# pagetailor + Next.js (App Router)

`pagetailor/` was created with `npx pagetailor init`; `pagetailor/components/index.js` is generated by `npx pagetailor registry` (rerun it after editing `registry.yaml`).

- `app/api/page/[page]/route.js`: server-only route handler, calls `resolve()` with `user` and `role` from the query string and returns `{ page, spec, errors }`.
- `app/layout.js`: reads `tokens.yaml` on the server and injects the `--pt-*` CSS variables.
- `app/PageClient.jsx`: client component, fetches the route and renders `<Page>` from `@aeratic/pagetailor/client` with the generated registry.

`next.config.js` only needs `transpilePackages: ["@aeratic/pagetailor"]` (the package ships `.jsx`). Run with `npm install && npm run dev`, then open `/?user=giulia&role=marketing`.
